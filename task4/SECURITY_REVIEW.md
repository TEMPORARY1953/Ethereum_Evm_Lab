# Проверка страницы подписи Task 4

Дата: 2026-10-22. Проверены `scripts/sepolia_metamask.py`, `sepolia_signer.js`,
`sepolia_signer.html`, CSS, используемый read-only модуль `../task2/sepolia_rpc.py`,
Foundry deployment script, исходники ERC20 и тестовые сценарии.
Это проверка кода и поведения в данном проекте, не независимый аудит MetaMask или RPC-провайдера.

## Исправления по результатам проверки

Добавлен отдельный предварительный просмотр параметров с комиссией перед каждой подписью.
Добавлены серверные резервирования, привязка сохранённого состояния к planId, защита от
неопределённого ответа кошелька и повторов в разных вкладках. Явный отказ MetaMask (4001)
освобождает соответствующее резервирование; неизвестный результат требует восстановления.
Добавлены проверка ровно одного аккаунта, восстановление по hash, автоматический read-only
опрос receipts и проверка mint-баланса на блоке транзакции. CSP дополнена ограничениями
connect-src/form-action/object-src; серверный allowlist сужен до необходимых методов.
