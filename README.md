# Лабораторная Ethereum / EVM

Все материалы находятся внутри текущего проекта. Работа выполнена по исходному заданию:
код и доступные проверки — локально; MetaMask, faucet и все публичные транзакции —
**только ручные инструкции**. Агент не создаёт реальные кошельки, не отправляет
транзакции и не разворачивает контракты в Sepolia или других публичных сетях.
**Сетевые операции не выполнены.** Из терминала недоступна загрузка инструментов.

## Быстрая локальная проверка

```powershell
./verify.ps1
```

Если Windows запрещает запуск `.ps1`, можно разрешить только этот дочерний процесс,
не меняя системную политику:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1
```

Скрипт использует установленный Python либо найденный runtime Codex; можно передать
`-PythonPath 'ПУТЬ_К_PYTHON_EXE'`. Он ничего не отправляет в сеть. Результаты пишутся
в `checks/`. Код завершения 0 = все проверки пройдены; 1 = ошибка; 2 = часть проверок
BLOCKED. В текущем окружении ожидается 2: **Foundry не установлен**.

Можно отдельно:

```powershell
node task1/build_program.mjs --check
python -B -m unittest discover -s task1 -v
python -B -m unittest discover -s task2 -v
python -B -m unittest discover -s task3 -v
python -B verify_artifacts.py
```

## Локальный запуск и ручная часть лабораторной

1. Запустить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_local.ps1`.
   Он автоматически устанавливает Foundry и solc из официальных источников и запускает
   локальные проверки. Ручное скачивание каждого EXE не требуется; детали —
   [.tools/README.md](.tools/README.md). В среде агента загрузка заблокирована sandbox.
2. Результаты установки, тестов и Anvil сохраняются в `checks/`.
3. Для самостоятельной сдачи выполнить инструкции [Task 2](task2/README.md): установить
   официальный MetaMask, создать отдельный тестовый аккаунт, включить Sepolia и получить
   test ETH. Альтернативный encrypted keystore описан для локальной подписи пользователем.
   Никогда не передавать пароль/seed/private key в чат или отчёт.
4. Самостоятельно узнать адрес коллеги, выполнить перевод Task 2 и сохранить настоящий hash.
5. Использовать настоящий hash и свой публичный адрес при кодировании Task 3;
   отправку сообщения выполнить вручную по инструкции.
6. При необходимости самостоятельно выполнить Sepolia-команды Task 4 и сохранить
   реальные receipts. Эти команды агент не запускает.
7. Проверить Etherscan и заполнить [FINAL_REPORT.md](FINAL_REPORT.md) настоящими результатами.

В проекте нет реальных кошельков, открытых приватных ключей, seed phrase или вымышленных
подтверждений. Исходный код никуда не публиковался. Инструкции со словами `<REAL_...>`
и `<YOUR_...>` требуют замены placeholders и не являются готовыми данными сети.
